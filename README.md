# EVENT RSVP & CHECK-IN SYSTEM 

Event RSVP system for the students where they can register for events. They can either be an attendee or an organizer. It can also register what event they are RSVP-ing. Lastly, it is able to determine the status of the invite whether it is pending, confirmed, or waitlisted. The students are also allowed to either update or view their details. 

## Interfaces 

- User
- Event
- RSVP

## How to Run

```bash
npm install

npx ts-node src/index.ts
```
